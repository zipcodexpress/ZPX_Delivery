Design a locker set

1. Define Small, Mid, Large or X-large box models with physical dimensions. 2. Place box models by row, column and door address in a body model, then mark the layout ready. 3. Create an unbound locker set, select body models and assign body sequence and controller address. 4. Bind the completed set to an empty inactive site location. Generated boxes remain frozen until separate commissioning.

Box models → Body models → Body-box layouts → Locker sets

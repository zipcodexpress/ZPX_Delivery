Design a locker set

1. Define Small, Mid, Large or X-large box models with physical dimensions. 2. Place those box models by row and column in a body model, then mark the layout ready. 3. Open an inactive locker at its installation site and select ready body models in installation order. Boxes are generated from each selected layout and remain frozen until separate hardware commissioning.

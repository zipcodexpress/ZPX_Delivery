## Behavior implemented

ThinkPHP 8.1.4 runs HTTP lifecycle/routing with explicit routes, JSON errors,
request IDs and no-store responses. Composer 2.10.3 installs the PHP 8.3 lockfile
in containers. Business endpoints are still pending. No OpenAPI payloads changed.

The explicit `python3 scripts/dev.py seed` command creates only namespaced synthetic
development records. It runs atomically under a transaction advisory lock and uses
the restricted runtime role. Random passwords are hashed, emitted only after commit,
and neither rotated nor redisplayed by repeat runs. Local output was captured in an
owner-only, Git-ignored file; no passwords are recorded here.

The dataset has six users, twenty locker sites, one hub, two drivers, forty frozen
compartments and ten unpaid parcels with six/four destination grouping. It does not
fabricate contact verification, shipping eligibility, labels, custody or commissioned
hardware. Namespaces allow isolated synthetic test datasets without deleting local data.

Migration 004 adds composite identity constraints for ownership projections. The
projection must reference both the compartment's locker and the manifest's matching
locker/generation. Existing migration files and checksums remain unchanged.

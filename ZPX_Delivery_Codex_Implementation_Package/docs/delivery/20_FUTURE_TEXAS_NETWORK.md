# Future Texas Network

Initial expansion corridors:

- Austin <-> Dallas/Fort Worth
- Austin <-> Houston
- Austin <-> San Antonio

## Intercity model

Endpoint locker
-> local relay/hub
-> city hub
-> scheduled linehaul
-> destination city hub
-> local relay
-> destination locker

## Driver categories

- gig driver
- commuter driver
- professional local route driver
- linehaul driver
- fleet partner
- property staff

## Scheduled routes

Use scheduled linehaul for predictable high-volume corridors.

Route planner should compare:
- gig-driver relay path
- scheduled linehaul path
- hybrid path

and choose based on SLA, cost, capacity, and reliability.

# Admin / Operations Console

## Required screens

### Shipment Monitor
- shipment
- customer
- origin/final destination
- current node/custodian
- current leg
- SLA
- active route plan
- exceptions

### Driver Monitor
- active drivers
- planned trips
- current tasks
- package count
- route progress
- task risk

### Locker Monitor
- online/offline
- occupancy
- free compartments by size
- packages waiting
- relay dwell time
- exception count

### Dispatch
- unassigned legs
- ranked drivers
- active offers
- expired offers
- manual assign
- reroute

### Claims
- custody timeline
- locker events
- driver events
- validation events
- payment/refund
- attachments

## Manual actions

All manual changes need:
- operator id
- reason code
- free-text note
- before state
- after state
- timestamp

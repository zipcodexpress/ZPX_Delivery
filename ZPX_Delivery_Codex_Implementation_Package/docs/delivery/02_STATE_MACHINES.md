# State Machines

## Shipment State Machine

DRAFT
-> QUOTED
-> PAYMENT_PENDING
-> READY_FOR_DEPOSIT
-> ORIGIN_RESERVED
-> DEPOSITED
-> ROUTE_PLANNED
-> WAITING_FOR_DRIVER
-> IN_TRANSIT
-> AT_RELAY_LOCKER
-> WAITING_FOR_NEXT_LEG
-> IN_TRANSIT
-> AT_DESTINATION_LOCKER
-> RECIPIENT_NOTIFIED
-> PICKED_UP
-> COMPLETED

Exception states:
- DELAYED
- ROUTE_EXCEPTION
- LOCKER_FULL
- VALIDATION_FAILED
- DAMAGED
- LOST
- RETURN_REQUESTED
- RETURNING
- CANCELLED

Do not allow application code to update arbitrary state strings.
All transitions must go through ShipmentStateService.

## Shipment Leg State Machine

PLANNED
-> AVAILABLE
-> OFFERED
-> ASSIGNED
-> READY_FOR_PICKUP
-> PICKED_UP
-> IN_TRANSIT
-> DELIVERED_TO_NODE
-> COMPLETED

Alternate:
OFFERED -> AVAILABLE
ASSIGNED -> AVAILABLE
ASSIGNED -> CANCELLED
IN_TRANSIT -> EXCEPTION
PLANNED -> CANCELLED

## Driver Task

DRAFT
-> OFFERED
-> ACCEPTED
-> ACTIVE
-> COMPLETED

Alternate:
OFFERED -> EXPIRED
OFFERED -> DECLINED
ACCEPTED -> CANCELLED
ACTIVE -> EXCEPTION

## Driver Trip

PLANNED
-> SEARCHING
-> MATCHED
-> ACTIVE
-> COMPLETED

Alternate:
PLANNED -> CANCELLED
SEARCHING -> CANCELLED
